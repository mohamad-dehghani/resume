# راهنمای ساختار جدید سایت

## چیدمان پوشه‌ها

```
index.html                      → صفحه اصلی با منو
assets/style.css                → تمام استایل‌ها، فونت‌ها و رنگ‌ها (تک فایل مرکزی)
01-education/                   → فصل تحصیلات (۳ صفحه)
02-work-experience/              → فصل سوابق شغلی (۳ صفحه)
03-teaching/                    → فصل تدریس (۲ صفحه)
```

## چطور فونت یا رنگ کل سایت را عوض کنم؟

فقط فایل `assets/style.css` را باز کن. بالای فایل، داخل `:root` یک بخش
به اسم «مقیاس سایز نوشته‌ها» هست — هر متغیر (مثل `--fs-body` یا `--fs-h1`)
روی همه‌ی صفحات همزمان اثر می‌گذارد. رنگ‌ها هم همان بالا تعریف شده‌اند
(`--bg`, `--ink`, `--line`, ...). دیگر لازم نیست فایل به فایل چیزی را
عوض کنی.

## هر صفحه چه چیزی مخصوص خودش دارد؟

هر فایل HTML یک بلوک `<style>` کوچک در `<head>` دارد که فقط چیدمان
همان صفحه را تنظیم می‌کند (سایز واترمارک پس‌زمینه، فاصله بالای محتوا،
سایز آیکن پایین صفحه). این‌ها به‌عمد جدا نگه داشته شده‌اند چون هدفشان
پر کردن فضای خالی متناسب با حجم محتوای همان صفحه است، نه فونت متن.
اگر صفحه‌ای فضای خالی زیاد دارد، معمولاً کافی است یکی از این مقادیر
(مثلاً `--content-margin-top` یا `--icon-size`) را کمی بزرگ‌تر کنی.

## نوار بالای صفحه (منو / قبلی / بعدی)

این نوار (`site-nav`) عمداً بیرون از قاب اصلی (`.canvas` با ابعاد
۱۰۸۰×۱۹۲۰) قرار گرفته. یعنی اگر بخواهی از یک صفحه برای استوری اینستاگرام
اسکرین‌شات بگیری، فقط کافی است دقیقاً همان مستطیل ۱۰۸۰×۱۹۲۰ (کلاس
`.canvas`) را بگیری — نوار ناوبری داخل تصویر نمی‌افتد.

## اضافه کردن یک فصل جدید (مثلاً «درباره من» یا «پروژه‌ها»)

۱. یک پوشه جدید بساز، مثل `04-projects/`
۲. یکی از فایل‌های موجود (مثلاً `work-1-overview.html`) را کپی کن و محتوایش را عوض کن — کلاس‌ها را دست نزن چون استایلشان مرکزی است
۳. مقادیر بلوک `<style>` بالای صفحه (واترمارک، فاصله‌ها) را با نگاه به صفحه در مرورگر تنظیم کن تا فضای خالی نداشته باشد
۴. یک کارت جدید در `index.html` داخل بخش `.chapters` اضافه کن که به اولین صفحه‌ی فصل جدید لینک بدهد
۵. لینک‌های «قبلی / بعدی» صفحه‌ی آخرِ فصل قبلی و اولِ فصل جدید را به هم وصل کن

## نکته درباره کیفیت عکس هنگام تبدیل به استوری

افت کیفیتِ عکس معمولاً از کم بودن مقیاس (scale / device pixel ratio) در
ابزار اسکرین‌شات است، نه از خودِ HTML. اگر از افزونه یا ابزار
screenshot استفاده می‌کنی، به‌جای مقیاس ۱x (که دقیقاً معادل ۱۰۸۰px
عرض واقعی است)، مقیاس ۲x یا ۳x را انتخاب کن تا خروجی با وضوح بالاتر
(مثلاً ۲۱۶۰ یا ۳۲۴۰ پیکسل) گرفته شود و در اینستاگرام تار به نظر نرسد.
اگر از افزونه‌های مرورگر مثل «GoFullPage» یا «Fireshot» استفاده می‌کنی،
اکثرشان یک گزینه‌ی resolution/scale دارند — همیشه بیشترین مقدار را
انتخاب کن.
